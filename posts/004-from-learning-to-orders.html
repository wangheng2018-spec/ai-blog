From Learning to Orders: Shipping 9 Projects in 3 Days

August 27, 2026 · 5 min read

In 72 hours I built and published 9 AI projects: a multi-agent sales team, a cost optimizer, a shop manager with dynamic routing, a RAG knowledge base with query rewriting, and more. Then I listed "AI custom development" on Xianyu — China's eBay — and started getting inquiries. This is the workflow that made it possible.

The principle: learn by shipping, not by watching

Most people consume tutorials. I produce projects. Each project is a self-contained, working, published artifact. No "TODO" commits, no half-finished notebooks. If it doesn't run and do something useful, it doesn't count.

The daily loop

  1. Morning: pick one capability to learn (e.g., "query rewriting").
  2. Midday: build the minimal version that demonstrates it — hand-written if possible.
  3. Afternoon: test it against real scenarios, not toy examples.
  4. Evening: publish to GitHub with a README, write down lessons learned.

What 9 projects in 3 days looks like

Day 1:  phone-valuer, phone-copywriter, ai-estimator-v2,
        shop-ai-cs, shop-product, portfolio
Day 2:  ai-sales-team, cost-optimizer, ai-shop-manager
Day 3:  ai-knowledge-shop (RAG + query rewrite + vectors)

The meta-skill: AI-assisted development

Here's the honest part: I didn't write every line by hand. I used AI assistants aggressively — but with a discipline that most people miss:

  • I always understand the code I ship. If I can't explain the BM25 formula, I don't ship it.
  • I test everything. Every project has passing test scenarios before it's published.
  • I keep the stack boring. Python, Flask, SQLite. No framework churn.
💡 The takeaway: AI tools multiply output, but only if you have the judgment to know what "done" means. Shipping is the skill. The tools are just speed.

From projects to orders

The endgame isn't the projects — it's the business loop. Listing on Xianyu turned a portfolio into a revenue channel. The first inquiry is worth more than the hundredth GitHub star, because it validates that someone will pay for what you build.

What's next

This is a 12-month sprint: English fluency, international clients, and deeper systems — memory, planning, productization. The projects from this week are the foundation. The blog you're reading is part of the same loop.
